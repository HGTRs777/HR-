# 公司 HR 制度智能问答需求 PRD

**版本：** 1.0  
**确认状态：** F01–F18 已冻结并完成开发  
**技术栈：** Vue 3、Vite、TypeScript、Flask、SQLAlchemy、SQLite、BGE、BM25、RRF、DeepSeek

## 1. 项目目标

建设一个基于企业制度知识库的 HR 智能问答系统。员工可以使用中文自然语言查询制度、连续追问、核对引用条款并进行条件推演；HR 管理员负责制度版本、索引、意见闭环和问答质量分析。

项目不建设员工档案、考勤审批、自动算薪、真实员工数据或复杂企业权限系统。

## 2. 用户与核心场景

- **员工：** 查询休假、考勤、差旅、福利和入离职制度；核对制度依据；按不同工龄、身份和事项条件推演；提交实名或匿名意见。
- **HR 知识管理员：** 上传和维护制度版本；重建检索索引；诊断 Top 5 命中；处理员工意见、复测原问题并沉淀回归用例；查看数据洞察。

## 3. 功能需求

| ID | 功能 | 验收要求 |
| --- | --- | --- |
| F01 | 中文自然语言问答 | 问题可提交并获得基于启用制度的回答 |
| F02 | 多轮对话 | 短追问能结合最近上下文独立检索 |
| F03 | 可点击证据链 | 点击引用跳转到正确制度版本并高亮条款 |
| F04 | 可信生成 | 伪造引用和无依据结论不得展示 |
| F05 | 会话历史 | 支持新建、查看、切换和删除匿名会话 |
| F06 | 管理认证 | 未登录不能访问管理接口，写操作校验 CSRF |
| F07 | 制度管理 | 支持 MD、TXT、PDF、DOCX 上传、预览、启停和约束删除 |
| F08 | 版本管理 | 编号与版本唯一，同一制度只有一个启用版本 |
| F09 | 索引管理 | 支持知识指纹、过期检测和原子重建 |
| F10 | 检索测试 | 展示 Top 5 向量、BM25 与 RRF 分数和名次 |
| F11 | 稳定性 | 模型异常时仅展示本地证据；索引异常时停止正式生成 |
| F12 | 情景澄清 | 条件不足时先追问关键槽位，不强行判断 |
| F13 | 情景推演 | 修改员工状态、工龄、事项或天数后重新生成判断 |
| F14 | 一问一办 | 输出结论、条件、时间线、材料和注意事项并绑定证据 |
| F15 | 答案保鲜 | 制度更新后标记历史答案，并支持按最新版刷新 |
| F16 | 共创意见箱 | 支持五类实名/匿名意见并自动附带问答证据快照 |
| F17 | 反馈闭环 | HR 可处理、退回、驳回、复测和固化唯一回归用例 |
| F18 | 数据洞察 | 支持查询质量、热门/未命中问题和反馈统计筛选 |

## 4. 数据与安全要求

- 数据库使用 SQLAlchemy 实体和 Alembic 迁移管理；SQLite 开启外键。
- 回答保存声明、证据、制度版本和知识指纹快照；历史数据不得被新版答案覆盖。
- 匿名浏览器会话通过 `X-Client-Session-ID` 隔离，不接入真实员工身份库。
- API 密钥、管理员密码和 Session 密钥只能通过环境变量或本地 `.env` 提供，不进入仓库。
- 制度文件最大 10 MB，仅允许 MD、TXT、PDF 和 DOCX；扫描版空文本 PDF、重复版本和恶意扩展名必须拒绝。

## 5. 质量与验收

- 25 条制度检索评测集满足 `Recall@3 ≥ 85%`；当前实测为 100%。
- 正常回答声明—证据映射正确率为 100%；知识库外问题不得生成制度结论。
- Pytest、Vitest、TypeScript strict、Playwright、依赖检查、迁移检查和生产构建必须通过。
- 桌面和移动端均不得出现阻断错误或横向溢出。
- 支持传统前后端分离开发，也支持 Waitress 在 `127.0.0.1:5000` 托管完整本地网站。
