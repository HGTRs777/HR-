# 公司 HR 制度智能问答用户手册

## 员工端

系统内置内容统一标记为“实训模拟企业 HR 制度知识库”，仅用于课程实训和功能验证，不代表任何真实企业的制度、待遇或承诺。

打开 `http://127.0.0.1:5173/`，使用员工演示账号 `staff`、密码 `88888888`，并完成页面上的一次性滑动拼图验证。登录后，查询历史和意见记录会稳定归属到员工账号；问答会自动使用该账号已配置的部门、岗位、入职日期、员工状态、累计工龄、负责人、HRBP 和年假余额，空字段显示“未配置”。

1. 左侧“历史对话”侧边栏用于新建、切换和删除会话；可点击侧栏顶部按钮隐藏或重新展开。历史标题不显示“[演示]”前缀，标题过长时将鼠标停留在该项上即可滚动查看全文。
2. 页面首先显示“今天想了解什么？”，常问按钮与输入框都进入当前问答会话；中间“制度咨询”只展示一次直接答案和最多两条必要解释，不重复完整流程或制度原文。
3. 右侧“我的情况与办理助手”只显示当前问题相关的少量已使用条件、真正缺失的条件、办理清单/流程和制度依据入口。完整员工资料默认收起，可点击页面右上角员工姓名查看；隐藏资料不影响后台业务判断。
4. 数值条件会按当前员工类型、制度明确上限和系统真实额度/余额限制可填范围；未找到可靠上限时不会编造固定最大值。提交或修改非敏感条件后，系统重新执行条件判断、制度检索、回答和办理清单，并提示“条件已更新，回答和办理建议已重新计算。”清单只展示员工可以执行的具体动作，不把制度名称或条款原文当作待办；第一条未勾选任务就是“下一步”。
5. “查看流程”展示事项应经过的人员或环节，不表示真实审批进度。直属负责人和 HRBP 有档案姓名时显示姓名，没有时明确显示“当前系统未配置具体人员”；系统不会猜测经办人。条件或制度版本变化后，稳定任务会按任务 ID 保留勾选状态，无法可靠匹配的已完成任务会重置并提示。只有服务端能够可靠计算时才显示预计完成时间。
6. 点击结论或清单中的制度依据，系统通过弹窗打开对应制度版本并高亮条款。
7. 若回答显示“相关制度已更新，建议重新核验”，点击“按当前制度重新回答”；系统保留旧回答和旧清单，不覆盖历史。
8. 每条回答下可选择“有帮助”或“有问题”。问题类型和详细说明通过原有意见系统提交，并自动关联当前会话、问题、回答及制度证据；意见中心以自然中文时间线展示 HR 处理进度。取消匿名后系统自动使用当前员工账号姓名与工号，无需再次填写姓名。

若出现“依据不足，已拒答”，表示当前启用制度没有足够依据；若出现“仅展示本地证据”，表示 DeepSeek 不可用，页面只展示检索原文，不生成制度结论。

## HR 管理端

打开 `http://127.0.0.1:5173/admin`，使用 HR 演示账号 `admin`、密码 `88888888`，并完成页面上的一次性滑动拼图验证。

### 制度与索引

1. 上传 Markdown、TXT、PDF 或 DOCX，填写制度编号、版本、分类和生效日期。
2. 新版本先作为草稿保存；预览并确认解析条款后再启用。
3. 同一制度只能启用一个版本；启用新版会原子停用旧版。
4. 制度变化后若索引显示过期，点击“更新制度索引”。系统会生成完整的新检索快照，并在成功后一次切换；首次加载向量模型可能需要 1–3 分钟，红框提示会提醒保持页面开启，前端最长等待 180 秒。
5. “Top 5 检索质量验证”是发布后的高级抽查工具。运行后下方直接显示“合格/不合格”、返回依据数量和首条命中；点击“查看诊断详情”可在弹窗中核对向量、BM25、RRF 分数及条款原文。它不负责构建索引，因此与索引发布不重复。

### 反馈治理

点击退出登录旁的“意见处理”进入独立反馈治理界面。

1. 按状态、类型、制度或日期筛选意见。
2. 合法流程为“待处理 → 处理中 → 已解决”，也可退回待处理或驳回。
3. 点击“复测原问题”检查原证据稳定锚点是否仍进入当前 Top 5。
4. 只有“已解决且最近复测通过”的意见可固化为唯一回归用例。
5. 所有处理动作只追加时间线事件，不覆盖历史。

### 问题中心

系统默认每 24 小时扫描一次启用知识库、匿名问答结果和制度反馈。HR 可在“问题中心”查看高/中/低风险线索、结构化扫描依据与建议动作，也可点击“立即扫描”。未配置 DeepSeek 时页面会标记“规则降级审计”，仍可发现高频未回答、制度缺失反馈和缺少办理要素等问题。

HR 治理首页顶部提供“制度管理、数据洞察、问题中心”三个模块快捷导航。制度版本、制度索引和 Top 5 检索统一归入“制度管理”；未选中的入口只显示图标，点击后展开模块名称并平滑跳转，手动滚动页面时导航也会自动展开当前所在模块。

### 数据洞察

仪表盘展示查询量、可信命中率、拒答/澄清/降级率、平均耗时、反馈待办、回归用例、热门/未命中问题和反馈分类。可信命中率按已经形成最终结果的问答计算，仍处于条件澄清阶段的问题不进入分母；卡片同时展示全部查询的原始命中率和样本数，避免筛选后产生误导性的 100%。

## 安全与数据边界

- 不要在问题、情景或意见中填写身份证号、手机号、工资明细等敏感信息。
- 员工和管理员退出演示时都应点击“退出登录”。
- 制度文件仅使用虚构或已获授权的数据；扫描版无文本 PDF 不支持解析。
- 本系统是制度信息辅助工具，依据不足时应向 HR 人工确认。
