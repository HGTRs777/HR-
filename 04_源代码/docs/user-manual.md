# 公司 HR 制度智能问答用户手册

## 员工端

打开 `http://127.0.0.1:5000/`。员工无需登录，浏览器只生成匿名会话标识，不接入真实员工档案。

1. 选择示例问题或输入中文制度问题并发送。
2. 条件不足时，按页面提示选择员工状态、工龄或事项条件。
3. 在“情景沙盘”修改非敏感条件后点击“按新条件重新推演”，查看条件变化、结论和办事卡。
4. 点击结论下方的制度依据，右侧会打开生成时对应的制度版本并高亮条款。
5. 若回答显示“制度已更新”，点击“按当前制度刷新”；系统保留旧回答，不覆盖历史。
6. 在“制度共创”中提交回答错误、制度缺失、制度过期、表述不清或改进建议。匿名意见不保存姓名；实名意见只保存主动填写的姓名。
7. 最近意见会显示 HR 的处理状态、说明、复测与固化事件。

若出现“依据不足，已拒答”，表示当前启用制度没有足够依据；若出现“仅展示本地证据”，表示 DeepSeek 不可用，页面只展示检索原文，不生成制度结论。

## HR 管理端

打开 `http://127.0.0.1:5000/admin`，使用初始化时创建的管理员登录。

### 制度与索引

1. 上传 Markdown、TXT、PDF 或 DOCX，填写制度编号、版本、分类和生效日期。
2. 新版本先作为草稿保存；预览并确认解析条款后再启用。
3. 同一制度只能启用一个版本；启用新版会原子停用旧版。
4. 制度变化后若索引显示过期，点击“重建并原子发布”。
5. 在 Top 5 检索诊断输入问题，核对向量、BM25 和 RRF 分数及条款位置。

### 反馈治理

1. 按状态、类型、制度或日期筛选意见。
2. 合法流程为“待处理 → 处理中 → 已解决”，也可退回待处理或驳回。
3. 点击“复测原问题”检查原证据稳定锚点是否仍进入当前 Top 5。
4. 只有“已解决且最近复测通过”的意见可固化为唯一回归用例。
5. 所有处理动作只追加时间线事件，不覆盖历史。

### 数据洞察

仪表盘展示查询量、可信命中率、拒答/澄清/降级率、平均耗时、反馈待办、回归用例、热门/未命中问题和反馈分类。筛选只改变统计口径，不关联员工档案。

## 安全与数据边界

- 不要在问题、情景或意见中填写身份证号、手机号、工资明细等敏感信息。
- 管理员退出演示时应点击“退出登录”。
- 制度文件仅使用虚构或已获授权的数据；扫描版无文本 PDF 不支持解析。
- 本系统是制度信息辅助工具，依据不足时应向 HR 人工确认。
