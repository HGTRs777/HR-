## 3. F18 与异常/安全验证

- F18：查询量、命中/拒答/澄清/降级率、平均耗时、反馈待办、回归用例、排行和分布聚合通过；日期、制度和状态过滤及空数据均通过。
- 伪造证据 ID：生成结论被移除，最终拒答，不暴露伪造引用。
- 非法模型 JSON：Pydantic 校验失败后进入本地证据降级。
- 模型超时：异常统一转换为模型生成错误并进入降级。
- 索引过期：启用版本指纹变化后停止正式生成并提示重建。
- 重复版本：返回 409，不产生重复数据。
- 恶意/不支持文件：扩展名白名单、解析校验与大小上限分别返回 415/413；扫描版空文本 PDF 被拒绝。
- 并发重建：非阻塞锁使第二次重建返回 409。
- 敏感/未知情景字段：返回 400，不进入会话数据。
- 管理端：Session、密码哈希、CORS 凭据白名单与 CSRF 写保护均有自动测试或契约约束。
